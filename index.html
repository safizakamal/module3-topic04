Notice the difference

Data are individual facts such as CustomerID, VehicleID and StartDate.

Information is the useful result produced when the system processes those facts—for example, a confirmed booking for Aisyah.

Users normally do not type SQL commands. They interact with an application. The application handles the request and communicates with the database.

💡 Where do C++ and MySQL fit?

A programming language such as C++ can be used to build application logic. A database system such as MySQL can manage stored data. Software called a database connector allows them to communicate.

You do not need to learn connector code here. The important idea is the communication flow.

📖 LEARN 4 · CONNECT TO WHAT YOU ALREADY KNOW

The Buttons May Be New — The Database Operations Are Not

➕ Add Customer

Behind the action, the system needs to create/store a customer record.

You met this idea with INSERT.

🔎 View Vehicles

The system needs to retrieve vehicle records.

You met this idea with SELECT.

✏️ Edit Booking

The system needs to change an existing record.

You met this idea with UPDATE.

🗑️ Cancel Record

The system may need to remove a record safely.

You met this idea with DELETE.

A graphical button does not replace the database operation. It gives the user an easier way to request that operation.

📖 LEARN 5 · SYSTEMATIC & RESPONSIBLE DATA HANDLING

A Working System Must Also Handle Data Carefully

✓ Validate

Check required values before saving. Rental dates should make sense and required IDs should be present.

🔗 Maintain Relationships

A booking should refer to a valid customer and a valid vehicle.

⚠️ Confirm Important Actions

Ask for confirmation before actions that may remove or change important records.

🔒 Use Data Responsibly

Display only information needed for the task and avoid exposing unnecessary customer details.

Responsible system development is not only about making the program work. It is also about handling data correctly, consistently and appropriately.
